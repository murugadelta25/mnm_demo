--------------------------------------------------------------------------------
  APPLICATION OVERVIEW
--------------------------------------------------------------------------------

  Name      : Titan OEE — PMS Production Dashboard
  Frontend  : React + Vite  (Port 5173)
  Backend   : FastAPI + SQLAlchemy  (Port 8000)
  Database  : MySQL
  Realtime  : WebSocket

  Screens:
    /dashboard    — OEE KPIs, charts, filters, CSV/Excel export
    /planning     — Production planning (daily/weekly/monthly)
    /entry        — Manual OEE data entry
    /model-change — Model change requests and approvals
    /breakdown    — Machine status layout, breakdown tickets
    /maintenance  — Maintenance ticket management
    /machines     — Machine configuration and PLC integration (admin only)
    /config       — System configuration (admin only)
    /alerts/email — Email alert configuration (admin only)

  Default Login Accounts:
    Username       Role          Password
    ----------     ----------    ----------
    admin          admin         admin123
    supervisor1    supervisor    sup123
    operator1      operator      op123
    maintenance1   maintenance   maint123

  IMPORTANT: Change all passwords after first login.

================================================================================
  SECTION 1 — WINDOWS SETUP (Local Development)
================================================================================

  PREREQUISITES — Install these first if not already installed:

    1. Python 3.11 or higher
       Download: https://www.python.org/downloads/
       During install: CHECK "Add Python to PATH"

    2. Node.js 20 LTS
       Download: https://nodejs.org/

    3. MySQL 8.0
       Download: https://dev.mysql.com/downloads/installer/
       Note your root password during installation.

    4. Git (optional but recommended)
       Download: https://git-scm.com/

  -----------------------------------------------------------------------
  STEP 1 — DATABASE SETUP (Run once)
  -----------------------------------------------------------------------

  Open PowerShell and run:

    mysql -u root -p < "database\schema.sql"

  When prompted, enter your MySQL root password.

  If you are updating an existing installation, also run migrations:

    mysql -u root -p eap_pms < "database\migrate_plans.sql"
    mysql -u root -p eap_pms < "database\migrate_machines.sql"
    mysql -u root -p eap_pms < "database\migrate_email_logs.sql"

  -----------------------------------------------------------------------
  STEP 2 — BACKEND SETUP (Run once)
  -----------------------------------------------------------------------

  Open PowerShell Terminal 1:

    cd "d:\Project documents\2026\TITAN_DEMO_Update\titan-oee\backend"

  Create virtual environment (first time only):

    python -m venv venv

  Activate virtual environment:

    .\venv\Scripts\Activate.ps1

  If you get a script execution error, run this first:

    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

  Install Python packages (first time only):

    pip install -r requirements.txt

  Configure environment file (first time only):

    copy .env.example .env

  Open .env in Notepad and set your MySQL password:

    notepad .env

    Change this line to match your MySQL root password:
    DATABASE_URL=mysql+pymysql://root:YourPassword@localhost:3306/eap_pms

  -----------------------------------------------------------------------
  STEP 3 — FRONTEND SETUP (Run once)
  -----------------------------------------------------------------------

  Open PowerShell Terminal 2:

    cd "d:\Project documents\2026\TITAN_DEMO_Update\titan-oee\frontend"

  Install npm packages (first time only):

    npm install

  The frontend .env is already configured for local Windows use:

    VITE_API_URL=http://localhost:8000
    VITE_WS_URL=ws://localhost:8000

  -----------------------------------------------------------------------
  STEP 4 — RUNNING THE APPLICATION (Every time)
  -----------------------------------------------------------------------

  OPTION A — One-click start (recommended):

    Double-click START_ALL.bat
    OR run in PowerShell:
    .\START_ALL.ps1

  OPTION B — Manual (two separate terminals):

  Terminal 1 — Backend:

    cd "d:\Project documents\2026\TITAN_DEMO_Update\titan-oee\backend"
    .\venv\Scripts\Activate.ps1
    uvicorn app.main:app --reload --port 8000

  Terminal 2 — Frontend:

    cd "d:\Project documents\2026\TITAN_DEMO_Update\titan-oee\frontend"
    npm run dev

  Open browser:

    http://localhost:5173

  -----------------------------------------------------------------------
  WINDOWS — WHAT TO RUN EACH TIME vs ONCE
  -----------------------------------------------------------------------

    Task                          Every time?   Notes
    --------------------------    -----------   ---------------------------
    MySQL service                 NO            Auto-starts with Windows
    Activate venv                 YES           Before running uvicorn
    uvicorn (backend)             YES           Keep terminal open
    npm run dev (frontend)        YES           Keep terminal open
    pip install                   NO            Only if requirements change
    npm install                   NO            Only if package.json changes
    Database schema/migrations    NO            Only for new installations

================================================================================
  SECTION 2 — UBUNTU SERVER SETUP
================================================================================

  -----------------------------------------------------------------------
  STEP 1 — INSTALL SYSTEM DEPENDENCIES
  -----------------------------------------------------------------------

  Open terminal on Ubuntu and run:

    sudo apt update && sudo apt upgrade -y

  Install Python 3:

    sudo apt install -y python3 python3-pip python3-venv

  Install Node.js 20:

    curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
    sudo apt install -y nodejs

  Verify installations:

    python3 --version
    node --version
    npm --version

  Install MySQL:

    sudo apt install -y mysql-server
    sudo systemctl enable mysql
    sudo systemctl start mysql

  -----------------------------------------------------------------------
  STEP 2 — CONFIGURE MYSQL
  -----------------------------------------------------------------------

  Secure MySQL and create database:

    sudo mysql

  Inside MySQL shell, run these commands:

    CREATE DATABASE eap_pms;
    CREATE USER 'titan_user'@'localhost' IDENTIFIED BY 'StrongPassword123';
    GRANT ALL PRIVILEGES ON eap_pms.* TO 'titan_user'@'localhost';
    FLUSH PRIVILEGES;
    EXIT;

  Load the database schema:

    mysql -u titan_user -p eap_pms < ~/titan-oee/database/schema.sql

  Run all migrations:

    mysql -u titan_user -p eap_pms < ~/titan-oee/database/migrate_plans.sql
    mysql -u titan_user -p eap_pms < ~/titan-oee/database/migrate_machines.sql
    mysql -u titan_user -p eap_pms < ~/titan-oee/database/migrate_email_logs.sql

  -----------------------------------------------------------------------
  STEP 3 — CONFIGURE ENVIRONMENT FILES
  -----------------------------------------------------------------------

  Find your server's LAN IP address:

    hostname -I

  Example output: 192.168.1.100  (use YOUR actual IP in the steps below)

  Configure backend .env:

    cp ~/titan-oee/backend/.env.example ~/titan-oee/backend/.env
    nano ~/titan-oee/backend/.env

  Set these values:

    DATABASE_URL=mysql+pymysql://titan_user:StrongPassword123@localhost:3306/eap_pms
    SECRET_KEY=<generate with command below>

  Generate a secure secret key:

    python3 -c "import secrets; print(secrets.token_hex(32))"

  Copy the output and paste it as the SECRET_KEY value.

  Configure frontend .env (replace 192.168.1.100 with your actual IP):

    nano ~/titan-oee/frontend/.env

  Set these values:

    VITE_API_URL=http://192.168.1.100:8000
    VITE_WS_URL=ws://192.168.1.100:8000

  -----------------------------------------------------------------------
  STEP 4 — INSTALL APPLICATION DEPENDENCIES
  -----------------------------------------------------------------------

  Backend Python packages:

    cd ~/titan-oee/backend
    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    deactivate

  Frontend npm packages:

    cd ~/titan-oee/frontend
    npm install

  -----------------------------------------------------------------------
  STEP 5 — OPEN FIREWALL PORTS
  -----------------------------------------------------------------------

    sudo ufw allow 5173/tcp
    sudo ufw allow 8000/tcp
    sudo ufw reload
    sudo ufw status

  -----------------------------------------------------------------------
  STEP 6 — RUNNING THE APPLICATION
  -----------------------------------------------------------------------

  OPTION A — Using start.sh (recommended for manual start):

    cd ~/titan-oee
    chmod +x start.sh
    ./start.sh

  To stop:

    ./start.sh stop

  To start only backend:

    ./start.sh backend

  To start only frontend:

    ./start.sh frontend

  View logs:

    tail -f ~/titan-oee/backend.log
    tail -f ~/titan-oee/frontend.log

  OPTION B — Manual (two separate terminals):

  Terminal 1 — Backend:

    cd ~/titan-oee/backend
    source venv/bin/activate
    uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

  Terminal 2 — Frontend:

    cd ~/titan-oee/frontend
    npm run dev -- --host

  -----------------------------------------------------------------------
  STEP 7 — AUTO-START ON BOOT (systemd — recommended for production)
  -----------------------------------------------------------------------

  Create backend service:

    sudo nano /etc/systemd/system/titan-backend.service

  Paste this content (replace 'ubuntu' with your actual Linux username):

    [Unit]
    Description=Titan OEE Backend
    After=network.target mysql.service

    [Service]
    User=ubuntu
    WorkingDirectory=/home/ubuntu/titan-oee/backend
    ExecStart=/home/ubuntu/titan-oee/backend/venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
    Restart=always
    RestartSec=5
    StandardOutput=append:/home/ubuntu/titan-oee/backend.log
    StandardError=append:/home/ubuntu/titan-oee/backend.log

    [Install]
    WantedBy=multi-user.target

  Create frontend service:

    sudo nano /etc/systemd/system/titan-frontend.service

  Paste this content:

    [Unit]
    Description=Titan OEE Frontend
    After=network.target

    [Service]
    User=ubuntu
    WorkingDirectory=/home/ubuntu/titan-oee/frontend
    ExecStart=/usr/bin/npm run dev -- --host
    Restart=always
    RestartSec=5
    StandardOutput=append:/home/ubuntu/titan-oee/frontend.log
    StandardError=append:/home/ubuntu/titan-oee/frontend.log

    [Install]
    WantedBy=multi-user.target

  Enable and start services:

    sudo systemctl daemon-reload
    sudo systemctl enable titan-backend titan-frontend
    sudo systemctl start titan-backend titan-frontend

  Check service status:

    sudo systemctl status titan-backend
    sudo systemctl status titan-frontend

  Manage services:

    sudo systemctl start   titan-backend titan-frontend
    sudo systemctl stop    titan-backend titan-frontend
    sudo systemctl restart titan-backend titan-frontend

  -----------------------------------------------------------------------
  ACCESSING FROM WINDOWS COMPUTERS ON THE SAME NETWORK

  Once the app is running on Ubuntu, open any browser on any Windows PC
  connected to the same network and go to:

  No installation needed on Windows client machines — just a browser.

  Also accessible from:
    Tablets, phones, or any device on the same network.

  API documentation:
    http://192.168.1.100:8000/docs

================================================================================
  SECTION 3 — TRANSFERRING FROM WINDOWS TO UBUNTU
================================================================================

  -----------------------------------------------------------------------
  STEP 1 — CREATE PACKAGE ON WINDOWS
  -----------------------------------------------------------------------

  Open PowerShell in the project folder and run:

    cd "d:\Project documents\2026\TITAN_DEMO_Update\titan-oee"
    .\PACKAGE.ps1

  This creates titan-oee.zip (approx 2-5 MB).
  It automatically excludes node_modules, venv, __pycache__, .env files.

  -----------------------------------------------------------------------
  STEP 2 — TRANSFER THE ZIP TO UBUNTU
  -----------------------------------------------------------------------

  OPTION A — SCP over network (requires SSH):

    scp titan-oee.zip ubuntu@192.168.1.100:~/

  OPTION B — USB Drive:

    Copy titan-oee.zip to USB drive.
    Plug USB into Ubuntu server, then run:

      cp /media/usb/titan-oee.zip ~/

  OPTION C — Shared network folder:

    Copy titan-oee.zip to a shared folder accessible from Ubuntu.

  -----------------------------------------------------------------------
  STEP 3 — DEPLOY ON UBUNTU (automated — one command)
  -----------------------------------------------------------------------

  SSH into Ubuntu server from Windows:

    ssh ubuntu@192.168.1.100

  On Ubuntu, run:

    cd ~
    unzip titan-oee.zip
    cd titan-oee
    chmod +x deploy.sh
    ./deploy.sh

  The deploy.sh script will automatically:
    - Install Python3, Node.js, MySQL if missing
    - Prompt for MySQL credentials and create the database
    - Auto-detect server LAN IP and write frontend/.env
    - Generate a secure SECRET_KEY
    - Run all database migrations
    - Install all Python and npm packages
    - Open firewall ports 5173 and 8000
    - Offer to install systemd services for auto-start on boot
    - Start the application

  -----------------------------------------------------------------------
  STEP 4 — ACCESS FROM WINDOWS
  -----------------------------------------------------------------------

    Open browser on any Windows PC on the same network:
    http://192.168.1.100:5173

  -----------------------------------------------------------------------
  RE-DEPLOYING AFTER UPDATES
  -----------------------------------------------------------------------

  On Windows — repackage:

    .\PACKAGE.ps1
    scp titan-oee.zip ubuntu@192.168.1.100:~/

  On Ubuntu — redeploy:

    cd ~
    unzip -o titan-oee.zip
    cd titan-oee
    ./deploy.sh

  The deploy script is safe to re-run. It skips steps already completed.

================================================================================
  SECTION 4 — TROUBLESHOOTING
================================================================================

  -----------------------------------------------------------------------
  WINDOWS ISSUES
  -----------------------------------------------------------------------

  PowerShell script execution blocked:

    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

  MySQL command not found:

    Add MySQL bin folder to PATH:
    C:\Program Files\MySQL\MySQL Server 8.0\bin

  Backend fails to start — port already in use:

    netstat -ano | findstr :8000
    taskkill /PID <pid_number> /F

  Frontend fails to start — port already in use:

    netstat -ano | findstr :5173
    taskkill /PID <pid_number> /F

  pip install fails:

    python -m pip install --upgrade pip
    pip install -r requirements.txt

  -----------------------------------------------------------------------
  UBUNTU ISSUES
  -----------------------------------------------------------------------

  Windows PC cannot reach the Ubuntu server:

    sudo ufw status
    sudo ufw allow 5173/tcp
    sudo ufw allow 8000/tcp
    ss -tlnp | grep -E '5173|8000'

  Frontend shows API connection errors:

    cat ~/titan-oee/frontend/.env
    (Should show your server IP, not localhost)

    Fix if wrong:
    echo "VITE_API_URL=http://$(hostname -I | awk '{print $1}'):8000" > ~/titan-oee/frontend/.env
    echo "VITE_WS_URL=ws://$(hostname -I | awk '{print $1}'):8000"   >> ~/titan-oee/frontend/.env
    ./start.sh stop && ./start.sh

  MySQL connection error:

    sudo systemctl status mysql
    sudo systemctl start mysql
    mysql -u titan_user -p eap_pms -e "SELECT 1;"

  Check if backend is running:

    ps aux | grep uvicorn

  Check if frontend is running:

    ps aux | grep vite

  View live logs:

    tail -f ~/titan-oee/backend.log
    tail -f ~/titan-oee/frontend.log

  Restart systemd services:

    sudo systemctl restart titan-backend titan-frontend
    sudo systemctl status titan-backend
